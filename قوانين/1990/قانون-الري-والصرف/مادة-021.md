# المادة 21 — المخالفات.
يكون مرتكباً لمخالفة يعاقب على ارتكابها بالجزاءات المنصوص عليها في المادة 23 كل شخص يرتكب أي
مخالفة لأحكام أي من المواد الآتية وذلك مع عدم الإخلال بأي عقوبة أشد يكون عرضة لها وفقا لأحكام أي
قانون آخر، والمواد هي:
(أ ) 7(1)،
(ب) 8،
(ج ) 11(1)،
(د ) 13(ب)(أولاً)، (ثانياً)، (رابعاً)، (خامساً) و (سادساً)،
(هـ) 14(ز) و(ك)،
(و ) 14(ل) بأن يصرف مياه الصناعة المعنية بدون الحصول على الموافقة مقدماً من جانب الوزارة،
(ز ) 15،
(ح ) 16،
(ط) 17(ب)(أولاً)،(ثانياً) و(رابعاً).
