# المادة 38 — المستحضرات الصيدلانية غير المطابقة للمواصفات.
(1) يعتبر أي دواء أو مستحضر صيدلاني أو مستلزم طبي
أو مستحضر تجميل غير مطابق للمواصفات إذا لم يستوف شروط المواصفة المطلوبة.
(2) لا يجوز توزيع أو بيع أو عرض للبيع أي دواء أو مستحضر صيدلاني أو مستلزم طبي أو مستحضر تجميل إذا ثبت بالتحليل المعملي أنه غير مطابق للمواصفات.
