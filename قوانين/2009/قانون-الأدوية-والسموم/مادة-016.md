# المادة 16 — وجوب تسجيل الأدوية والمستحضرات الصيدلانية.
(1) لا يجوز لأي شخص تصنيع أو تحضير أو تجهيز أو
إستيراد أو توزيع أو بيع أو عرض للبيع أو تسليم لإعادة
البيع أي دواء أو مسـتحضر صيدلاني أو مستلزم طـبي أو
مستحضر تجميل إلا بعد تسجيله وفقاً لأحكام هذا القانون واللوائح الصادرة بموجبه.
(2) يستثنى من أحكام البند (1) التجهيزات التي تحضر داخل الصيدلية والعينات المصدقة وفقاً لأحكام هذا
القانون التي تستجلب لغرض التسجيل أو الدعاية أو الأبحاث أو أدوية الطوارئ التي يقررها المجلس.
