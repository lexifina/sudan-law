# المادة 104 — الإرهاب والمضايقة.
لا يجوز لأي شخص أن يجبر أي شخص على أي فعل أو امتناع يكون لذلك الشخص حق قانوني لفعله أو الامتناع عنه وذلك من:
( أ ) استعمال العنف أو الاستفزاز أو إهانة ذلك الشخص أو زوجته أو أطفاله أو إتلاف ممتلكاته،
(ب) تتبع ذلك الشخص من مكان لآخر،
(ج) إخفاء أية أدوات أو ملابس أو أي ممتلكات يملكها أو يستعملها ذلك الشخص أو يحرمه استعمالها.
(د ) مراقبة أو مضايقة أي شخص في منزله أو أي مكان آخر مقيم فيه أو في أي طريق يؤدي إلى ذلك المنزل أو المكان.
