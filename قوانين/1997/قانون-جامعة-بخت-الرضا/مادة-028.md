# المادة 28 — مجالس الأقسـام ووحدات التدريب.
(1) ينشأ في كل قسم أو وحدة تدريب مجلس برئاسة رئيس القسـم أو وحدة التدريب وعضوية جميع أعضـاء هـيئة التدريس بالقسم أو وحدة التدريب.
(2) تكون مهمة مجلس القسم أو وحدة التدريب بالإضافة إلى ما يضمن في النظم الأساسية واللوائح تنظيم النشاط العلمي والإدارى بالقسم أو وحدة التدريب وذلك تحت
إشراف مجلس الكلية أو المدرسة أو المعهد أو المركز.
