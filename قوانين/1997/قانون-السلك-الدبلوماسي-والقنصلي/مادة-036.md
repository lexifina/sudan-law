# المادة 36 — المحاسبة.
يخضع للمحاسبة، أي عضو دبلوماسي يرفض أو يهمل تنفيذ أي قانون أو لائحة سارية المفعول، أو أمر
مشروع صادر من رئيسه، أو يرفض أو يهمل أداء واجباته أو يسلك بفعل أو امتناع، سلوكاً منافياً لمقتضيات
وظيفته أو لا يليق بمركزه الرسمي، أو يتغيب عن الخدمة أو يتركها، أو يحكم بإدانته في تهمة جنائية ماسة
بالشرف أو الأمانة أو يرتكب أي مخالفة لأحكام المادة 35(2).
