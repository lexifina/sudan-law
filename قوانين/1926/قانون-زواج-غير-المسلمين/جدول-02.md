# الجدول الثاني
الطوائف المستثناة
(انظر المادتين 3 و 5)
القسم الأول
تكون الطوائف المذكورة فيما يلي هي الطوائف المستثناة بالمعني المقصود في هذا القانون وهي:
(أ ) كنيسة الروم الارثوذكس
(ب) كنيسة الأقباط الارثوذكس
(ج) الكنيسة الرومانية
(د ) كنيسة الروم الكاثوليكية
(هـ) الكنيسة المارونية
(و ) كنيسة السريان الكاثوليك
(ز ) كنيسة الأرمن الكاثوليك
(ح ) كنيسة الأقباط الكاثوليك
(ط ) كنيسة الكلدان الكاثوليك
(ى ) الطائفة اليهودية
القسم الثاني
تكون مجموعة الطوائف المستثناة بالمعنى المقصود من هذا القانون على الوجه الآتي:
( أ) الكنيسة الرومانية الكاثوليكية
(ب) كنيسة الروم الكاثوليك
(ج ) الكنيسة المارونية
(د ) كنيسة السريان الكاثوليك
(هـ) كنيسة الأرمن الكاثوليك
(و ) كنيسة الأقباط الكاثوليك
(ز ) كنيسة الكلدان الكاثوليك
