# المادة 16 — سلطة المسجـل في رفض طلب التسجيل أو قبوله أو تعديله.
(1) يجوز للمسجل أن يرفض طلب تسجيل أية علامة تجارية
أو يقبله دون شروط أو وفقاً لأية شروط أو تعديلات أو
تنقيح أو قيود بشأن طريقة ومكان الاستعمال أو وفقاً لأية
شروط أخرى يراها ملائمة طبقاً لأحكام هذا القانون.
(2) يجوز استئناف قرار تسجيل العلامة التجارية أو أي شروط أو تعديل أو تنقيح أو قيود يضعها المسجل أمام المحكمة.
