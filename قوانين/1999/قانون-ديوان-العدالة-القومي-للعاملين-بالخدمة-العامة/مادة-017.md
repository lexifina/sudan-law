# المادة 17 — إلتزام العاملين.
مع مراعـاة أي إلتزامات قـانونية أخرى يلتزم العمال في الديوان بالآتي:
(أ ) أداء أعمالهم بكل جد وإخلاص وأمانة،
(ب) مراعاة السلوك الحسن والتعاون مع المتظلمين والطاعنين،
(ج ) عدم طلب أي معلومات من الوحدات إلا لغرض يتعلق بموضوع الطعن أو التظلم،
(د ) عدم إفشاء أو نشر أي معلومات أو وثائق توفرت لديهم بسبب إجراءات التحقيق أو نظر التظلمات أو الطعون.
