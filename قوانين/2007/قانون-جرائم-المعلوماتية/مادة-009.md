# المادة 9 — إعاقة أو تشويش أو تعطيل الوصول للخدمة.
كل من يعوق أو يشوش أو يعطل عمداً، وبأي وسيلة، الوصول إلى
الخدمة أو الدخول إلى الأجهـزة أو البرامج أو مصـادر البيانات أو
المعلومات عن طريق شبكة المعلومات أو أحد أجهزة الحاسـوب أو ما في حكمها،
يعاقب بالسجن لمـدة لا تجاوز سنتين أو بالغرامة أو بالعقوبتين معاً.
