# المادة 8 — إيقاف أو تعطيل أو إتلاف البرامج أو في البيانات أو المعلومات.
كل من يدخل بأي وسيلة، نظاماً أو وسائطاً أو شبكات المعلومات وما
حكمها، ويقوم عمداً بإيقافها أو تعطيلها أو تدمير البرامج أو
البيانات أو المعلومات أو مسحها أو حذفها أو إتلافها، يعاقب بالسجن
لمدة لا تجاوز ست سنوات أو بالغرامة أو بالعقوبتين معاً.

> حاشية: (4) قانون رقم 40 لسنة 1974.
