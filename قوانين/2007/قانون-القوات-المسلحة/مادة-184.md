# المادة 184 — التهم والبيانات الكاذبة.
يعاقب بالسجن مدة لا تجـاوز خمس سـنوات أو بأي عقوبة أقل كل من:
( أ) يوجه اتهاماً ضد أي شخص أو يدلى ببيانات كاذبة وهو يعلم أن ذلك الاتهام أو تلك البيانات كاذبة،
(ب) يدلى عمداً بأقوال كاذبة تتعلق بأخلاق أي شخص قاصداً بذلك إدانته أو تبرئته أو حرمانه من
أي امتياز أو حق أو منحه أي امتياز أو حق،
(ج) يتخذ أي إجراء جنائي ضد أي شخص أو يتسبب فيه أو اتهامه كذباً بارتكاب جريمة قاصدا ًبذلك
الأضرار به مع علمه بعدم وجود أساس معقول أو مشروع لذلك الإجراء أو الاتهام.
