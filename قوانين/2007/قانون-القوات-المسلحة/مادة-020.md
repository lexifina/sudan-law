# المادة 20 — الرتب النظامية.
(1) تكون الرتب النظامية لضباط القوات المسلحة على الوجه الآتي:
( أ ) مشير،
(ب) فريق أول،
(ج) فريق،
( د) لواء،
(هـ) عميد،
( و ) عقيد،
( ز ) مقدم،
( ح ) رائد،
(ط ) نقيب،
(ي ) ملازم أول،
(ك ) ملازم.
(2) لا تمنح رتبة المشير إلا لرئيس الجمهورية إذا كان عسكرياً أو للقائد العام.
(3) تكون الرتب النظامية لضباط الصف والجنود بالقوات المسلحة على الوجه الآتي:
( أ) مساعد،
(ب) رقيب أول،
(ج) رقيب،
( د) عريف،
(هـ) وكيل عريف،
( و) جندي،
( ز) أي رتب أخرى مستحدثة.
(4) تحدد اللوائح والنظم الالقاب العسكرية وكيفية حملها.

> حاشية: (15) قانون رقم 40 لسنة 1974.
