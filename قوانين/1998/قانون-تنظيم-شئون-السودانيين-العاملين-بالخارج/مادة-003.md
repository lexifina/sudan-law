# المادة 3 — تفسير. |
| فى هذا القانون، ما لم يقتض السياق معنى آخر:
| | "الأمين العام" | يقصد به الأمين العام للجهاز المعين بموجب أحكام المادة 11،
| | "الأمين العام للضرائب" | يقصـد به الأمين العـام لديـوان الضرائب،
| | "الجهاز" | يقصد به جهاز تنظيم شئون السودانيين العاملين بالخارج المنـشأ بموجب أحكام المادة 4،
| | "العاملون بالخارج" | يقصد بهم جميع السودانيين العاملين بالخارج الذين يعملون بإقامة أعمال رسمية ويشمل ذلك أي شخص يكون قد أقام لمدة تزيد على ستة أشهـر متصلة بشرط أن يكون قد زاول عملاً خلال هذه المدة، كما يشمل ذلك المعارين والعاملين في المنظمات الدولية والإقليمية بالخارج،
| | "فئة المساهمة" | يقصد بها فئة المساهمة الوطنية المفروضة على العاملين بالخارج بموجب أحكام الفصل الرابع،
| | "الكيانات" | يقصد بها جاليات وروابط العاملين بالخارج.
| | "المجلس" | يقصد به مجلس إدارة الجهاز المنشأ بموجب أحكام المادة 7،
| | "المؤتمر" | يقصد به المؤتمر العام للسودانيين العاملين بالخارج المنصوص عليه في المادة 13،
| | "الوزارة " | يقصد بها وزارة المالية والاقتصاد الوطني،
| | "الوزير" | يقصد به وزير المالية والاقتصاد الوطني،
| | "الوزير المختص" | يقصد به وزير وزارة مجلس الوزراء.

> حاشية: (1) قانون رقم (40) لسنة 1974 .
