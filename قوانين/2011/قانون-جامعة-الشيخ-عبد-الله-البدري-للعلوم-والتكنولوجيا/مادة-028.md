# المادة 28 — مجالس الأقسام ووحدات الجودة والاعتماد والتدريب.
(1) ينشأ في كل قسم أو وحدة الجودة والاعتماد والتدريب مجلس
برئاسة رئيس القسم أو وحدة الجودة والاعتماد والتدريب وعضوية
جميع أعضاء هيئة التدريس بالقسم أو وحدة الاعتماد والجـودة والتدريب.
(2) تكون مهمة مجلس القسم أو وحدة الاعتماد والجودة والتدريب بالإضافة إلى ما يضمن في النظم الأساسية واللوائح تنظيم النشاط العلمي والإداري بالقسم أو وحدة الجودة والاعتماد والتدريب وذلك تحت إشراف مجلس الكلية أو المدرسة أو المعهد أو المركز.
