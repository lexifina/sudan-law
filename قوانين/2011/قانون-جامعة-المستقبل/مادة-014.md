# المادة 14 — إنشاء مجلس الأساتذة وتشكيله.
ينشأ مجلس يسمى " مجلس الأساتذة " ويُشكل على النحو الآتى: ( أ ) الرئيس رئيساً (ب) نائب الرئيس عضواً
(ج ) نائب الرئيس للشؤون المالية والإدارية عضواً
( د ) مساعد الرئيس للشؤون العلمية عضواً ومقرراً
(هـ) مساعد الرئيس للبحث العلمي والتطوير عضواً
( و) أمين المكتبة عضواً
( ز) عميد شؤون الطلاب عضواً
(ح ) عمداء الكليات ومديرو المعاهد والمراكز أعضاءً
(ط ) رؤساء الأقسام ومنسقو البرامج التدريبية والدراسية أعضاءً
(ى ) ممثل واحد في مرتبة الأستاذية تختاره الكلية
أو المعهد أو المركز المعني. عضواً
