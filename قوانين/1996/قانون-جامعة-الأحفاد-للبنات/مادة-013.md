# المادة 13 — اختصاصات المجلس.
تكون للمجلس الاختصاصات الآتية:
( أ) وضع السياسات والخطط لتحقيق أغراض الجامعة وتطوير أدائها وتجويده وتحديث طرق أساليب عملها بناءً على توجيه مجلس الأمناء،
(ب) تقديم الدراسات والتوصيات التي تتصل بالخطط طويلة المدى والبرامج قصيرة المدة التي تهدف لتطوير الجامعة إلى مجلس الأمناء،
(ج ) تقدير الصرف المالى والإيرادات وتقديمها إلى مجلس الأمناء،
(د ) تحديد مسئوليات واختصاصات شاغلي المناصب العلمية والإدارية القيادية وفقاً للوائح،
(هـ) إعداد الموازنة السنوية العامة وفقاً للبرنامج قصير المدى ورفعها لمجلس الأمناء لإجازتها،
(و ) إصدار قواعد النظام في الجامعة وقواعد سلوك الطالبات،
(ز ) تحديد الرسوم والمنح الدراسية،
(ح ) أى مسائل أخرى يحيلها إليه مجلس الأمناء.
