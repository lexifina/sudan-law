# المادة 8 — إلغاء التسجيل.
يجوز للمسجل العام إلغاء تسجيل أي جماعة، إذا اقتنع بعد إجـراء التحريات اللازمة أن:
( أ) التسجيل بطريق الغش أو بناءً على بيانات غير صحيحة،
(ب) الجماعة قد خالفت أحكام هذا القانون أو اللوائح أو القرارات الصادرة بموجبه أو أحكام نظامها الأساسي،
(ج ) مجموع عدد أعضائها لا يقل عن خمسة وعشرين شخصاً.
