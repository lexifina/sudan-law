# المادة 16 — اختصاصات رئيس المجلس.
تكون لرئيس المجلس الاختصاصات الآتية:
( أ) رئاسة المجلس،
(ب) المساعدة في كل ما من شأنه تقوية الصلة بين المجلس والمؤسسات والهيئات الأخرى، لتحقيق أغراض الجامعة،
(ج ) إتخاذ المبادرات التي تكفل تحقيق أغراض الجامعة،
(د ) متابعة تنفيذ قرارات المجلس واللجنة وتقديمها للمجلس.

> حاشية: (5) القانون نفسه.
