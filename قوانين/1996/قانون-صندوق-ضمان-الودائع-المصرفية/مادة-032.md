# المادة 32 — العقوبات.
مع عدم الإخلال بأى عقوبة أشد في أي قانون آخر كل شخص يعد بياناً كاذباً مع علمه بذلك أو يغفل ذكر أي بيانات
جوهرية بسوء قصد فيما يتعلق بأى موازنة أو مستند آخر أو معلومات مطلوبة أو بيانات أعدت وفقاً لأحكام هذا القانون
أو يفشل في تقديم أي مستند أو بيان أو معلومات يكون ملزماً بتقديمها أو إعدادها، يعد مرتكباً جريمة ويعاقب عند الإدانة
بالسجن لمدة لا تجاوز ثلاث سنوات أو بالغرامة أو بالعقوبتين معاً.

> حاشية: (11) قانون رقم 40 لسنة 1974 .
