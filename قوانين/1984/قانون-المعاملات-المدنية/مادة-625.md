# المادة 625 — دعوى الشفعة.
لا تسمع دعوى الشفعة في الأحوال الآتية إذا:
(أ ) تم البيع بالمزاد العلنى وفق الاجراءات التي رسمها القانون،
(ب) وقع البيع بين الأصول والفروع أو بين الزوجين أو بين الأقارب حتى
الدرجة الرابعة أو بين الأصهار حتى الدرجة الثانية،
(ج ) نزل الشفيع عن حقه في الشفعة صراحة أو دلالة.
