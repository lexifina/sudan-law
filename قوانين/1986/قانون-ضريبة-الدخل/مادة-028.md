# المادة 28 — أوجه خصم معينة مسموح بها.
مع عدم الإخلال بعموم أحكام المادة 18(1) عند التثبت من الدخل
الشخصي لأي شخص عن أي فترة أساس يخصم من جملة القيمة
المقبوضة أو المعتبرة مقبوضة في تلك الفترة:
( أ) استقطاعات المعاش واستقطاعات مال التأمين واستقطاعات أي مشروع آخر لفوائد ما بعد الخدمة،
(ب) المكافأة المقبوضة عند إنهاء عقد الخدمة،
(ج ) أي قيمة يجوز خصمها بموجب الجدول الثاني الملحق بهذا القانون،
(د ) أي خصم آخر مما تقرره اللوائح.
