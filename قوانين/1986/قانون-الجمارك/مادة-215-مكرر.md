# المادة 215ـ
(1) إذا نشأت عند اتخاذ أي إجراءات جنائية أي مسألة تتعلق بدفع أو عدم دفع أي رسوم جمركية عن أي
بضائع أو تصديرها أو نقلها عبر الساحل أو تفريغها من أي سفينة أو شحنها فيها فيعتبر فشل المتهم
في إبراز المستندات الصحيحة بينة مبدئية على عدم دفع تلك الرسوم أو عدم مشروعية نقل تلك
البضائع أو استيرادها أو تصديرها أو نقلها عبر الساحل أو تفريغها من أي سفينة أو شحنها فيها
بحسب الحال.
(2) إذا حدث أي نزاع في أي قضية جمركية أو عند اتخاذ أي إجراءات بموجب المادة 194 لاسترداد أي وسيلة
للنقل أو أي بضائع استولى عليها ضابط الجمارك، حول ما إذا كانت الرسوم الجمركية الخاصة بأي بضائع
قد دفعت أو لم تدفع أو بصدد مشروعية استيراد أي بضائع أو تصديرها أو نقلها عبر الساحل أو تفريغها في
أي سفينة أو شحنها بحسب الحال فيقع عبء الإثبات على المدعي في تلك الإجراءات.
حظر تسليم البضائع المحجوزة
