# المادة 31 — سلطة إصدار اللوائح.
يجوز للمجلس أن يصدر اللوائح التنظيمية والقواعد والأوامر اللازمة لتنفيذ أحكام هذا القانون، ومع عدم الإخلال بعموم ما تقدم يجوز أن تتضمن تلك اللوائح والأوامر والقواعد المسائل الآتية:
( أ) تعيين لجان المجلس الفرعية وتحديد سلطاتها واختصاصاتها،
(ب) طريقة تقديم البيانات والمعلومات والمعاملات للمصرف والمجلس ولأي سلطة أخرى أو أي موظف حسب مقتضى الحال بما يتماشى مع قانون تنظيم العمل المصرفي لسنة 2004،
(ج ) كيفية إعداد البيانات المالية والحسابات والكشوفات،
(د ) الاتفاقيات والعقود التي تتصل بأعمال المصرف ومعاملاته،
(هـ) لوائح وشروط خدمة العاملين بالمصرف،
(و ) تحديد تصديق سقوفات التمويل بمختلف درجاتها،
(ز ) جميع اللوائح اللازمة لتنظيم وتنفيذ أعمال المصرف.
