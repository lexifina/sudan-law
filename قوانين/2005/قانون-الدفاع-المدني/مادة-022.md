# المادة 22 — الجرائم.
يعتبر مرتكباً جريمة كل شخص يقوم بأي من الأفعال الآتية:
( أ) رفض أو إهمال اتباع شروط نظم ومعايير الأسس الفنية الخاصة بإجراءات السلامة والوقاية المنصوص عليها في اللوائح الصادرة بموجب أحكام هذا القانون،
(ب) إقامة مساكن أو إعادة تشييدها في حرم الأنهار ومجاري السيول،
(ج ) التعدي أو القيام بأي عمل يؤدي إلى هدم أو إتلاف أو إعاقة السدود والجسور والمصارف الطبيعية مخالفة لأحكام المادة 17،
(د ) منح شهادات التراخيص والتأمين مخالفة لأحكام المادة 18،
(هـ) مخالفة أي أمر يصدر بموجب أحكام المادة 19.
