# الجدول الأول
( انظر المادة 2 )
الأمراض المعلن عنها
جميع الحشرات القرمزية أو البق المغير ( كوكيديا ) المتلف لأشجار الفاكهة أو الأشجار أو النباتات الأخرى ذات القيمة الاقتصادية.
دودة اللوزة الوردية ( بلايتيدرا قوسبيلا ).
الذراع السوداء أو بقعة الورقة ذات الزاوية ( باسيلاس مالفاسيرام ).
تجعد الورقة أو تغضن الورقة.
ذبابة العسلة.
ثاقبة ساق الذرة ( سيساميا كرينيا ).
