# المادة 34 — العقوبات.
(1) يعد مرتكباً لجريمة كل شخص:
( أ) يعد بياناً كاذباً يكون ملزماً بإعداده بموجب أحكام هذا القانون مع علمه بذلك،
(ب) يغفل ذكر بيانات جوهرية يكون ملزماً بذكرها تتعلق بأية موازنة أو مستند أو معلومات أو بيانات أٌعدت وفقاً لأحكام هذا القانون،
(ج) يفشل في تقديم مستند أو بيانات أو معلومات يكون ملزماً بتقديمها أو إعدادها بموجب أحكام هذا القانون.
(2) كل من يرتكب جريمة بموجب أحكام البند (1) يعاقب بالسجن لمدة لا تجاوز سنتين أو بالغرامة أو بالعقوبتين معاً.
