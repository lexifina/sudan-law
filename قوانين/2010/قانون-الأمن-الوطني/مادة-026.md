# المادة 26 — رُتب الأعضاء.
(1) تكون رُتب الضباط في الجهاز كالآتي:
( أ) فريق أول أمن،
(ب) فريق أمن،
(ج) لواء أمن،
(د ) عميد أمن،
(هـ) عقيد أمن،
( و) مقدم أمن،
( ز) رائد أمن،
(ح) نقيب أمن،
(ط) ملازم أول أمن،
(ي) ملازم أمن.
(2) تكون الرُتب الأخرى في الجهاز كالآتي:
( أ) مساعد أمن،
(ب) رقيب أول أمن،
(ج) رقيب أمن،
(د ) عريف أمن،
(هـ) وكيل عريف أمن،
(و) جندي أمن.
