# المادة 4 — الرسالة.
(1) يكون جهاز الأمـن الوطني جهـازاً لتنبيه أجهزة الدولة المختصة بحدوث أو قدوم خطر داخلي
أو خارجي يهدد البلاد أو أي جزء منها حرباً كان أو غزواً أو حِصاراً أو كارثة طبيعية أو بيئية،
أو تهديد سلامتها اقتصادياً أو نظامها الديمقراطي أو نسيجها الاجتماعي، ولإشاعة وبث
الطمأنينة وسط المواطنين.
(2) يكون الجهاز وخدمته مهنية وقومية تعكس التمثيل العادل للتنوع والتعداد بالسودان.
