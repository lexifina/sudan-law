# المادة 62 — عقوبة التصرف في الأسلحة والذخيرة والمهمات الأخرى.
يعاقب بالسجن لمدة لا تجاوز عشر سنوات، أو بالغرامة، أو بالعقوبتين
معاً، كل عضو يتصرف أو يأذن بالتصرف دون وجه حق في أسلحة
أو ذخيرة أو أدوات، أو مهمات أو معدات، أو آلات أو ملبوسات، تكون قد صرفت له لاستخدامها في أداء واجباته، أو تحت مسئوليته، أو عهدته، أو حراسته.
