# المادة 28 — مجالس الأقسام ووحدات التدريب.
(1) ينشأ في كل قسم أو وحدة تدريب مجلس برئاسـة رئيس القسم أو
وحدة التدريـب وعضـوية جميع أعضـاء هيـئة التدريس بالقسم أو وحدة التدريب.
(2) تكون مهمة مجلس القسم أو وحدة التدريب بالإضافة إلى ما يرد في النظم
الأساسية واللَّوائح، تنظيم النشاط العلمي والإداري بالقسم أو وحدة التدريب
وذلك تحت إشراف مجلس الكلية أو المدرسة أو المعهد أو المركز.
