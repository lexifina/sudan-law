# المادة 50 — سلطة إصدار اللًوائح والقواعد والأوامر.
(1) يصدر المراجع العام اللوائح والقواعد والأوامر اللازمة لتنفيذ أحكام هذا القانون.
(2) دون المساس بأحكام البند (1) يجوز أن تنص اللوائح على المسائل التالية:
(أ ) شروط خدمة المراجعين والعاملين وإجراءات تعيينهم وترقيتهم وتدريبهم،
(ب) إجراءات محاسبة المراجعين والعاملين بالديوان وتشكيل مجالس المحاسبة بأنواعها واختصاصاتها وسلطاتها،
(ج ) السلوك المهني والأخلاقي للمراجعين والعاملين،
(د ) بطاقة المراجعين بالديوان.
