# المادة 243 — عقوبة تزوير الدفاتر أو إخفائها أو الغش فيها.
إذا أتلف عضو المجلس أو المديرالعام أو الموظف أو المساهم
أو الملزم بالدفع بأية شركة في حالة التصفية أو شوه أو أبدل أو زور
أو أخفى بطريقة الغش أية دفـاتر أو أوراق أو ضـمانات أو أجرى
بطريق التزوير أو الغش أي قـيد في أي سجل أو دفتر حسـابات أو مستند للشركة
أو كان طرفاً في إجراء ذلك القيد قاصداً بذلك غش أي شخص أو خداعه يعاقب عند
الإدانة بالسجن مدة لا تجاوز سبع سنوات كما تجوز معاقبته بالغرامة.
