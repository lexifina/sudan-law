# المادة 3 — تطبيق.
يطبق هذا القانون على شاغلي المناصب الدستورية التنفيذية والتشريعية الآتية:
(أ ) رئيس الجمهورية ونائبيه،
(ب)رئيس المجلس الوطني ونائبيه،
(ج ) مساعدى رئيس الجمهورية ومستشاريه والوزراء القوميين ووزراء الدولة،
(د ) الوالى والوزير الولائي والمعتمد،
(هـ) رؤساء اللجان الدائمة والأعضاء بالمجلس الوطني،
(و ) رئيس ونائب رئيس مجلس الولاية ورائد المجلس الولائي ورئيس الهيئة النيابية ورؤساء اللجان الدائمة بمجلس الولاية وأعضاء مجالس الولايات.

> حاشية: (2) قانون التعديلات المتنوعة (القوانين المتأثرة بانفصال جنوب السودان ) لسنة 2012 رقم 20 لسنة 2012 .
