# المادة 23 — اختصاصات إدارة الامتحانات والتقويم وسلطاتها.
تكون لإدارة الامتحان والتقويم بالوزارة الاختصاصات والسلطات
الآتية:
( أ) وضع امتحانات الشهادة الثانوية وإجراء الامتحانات،
(ب) إصدار نتائج امتحانات الشهادة الثانوية وحفظها،
(ج ) معادلة شهادات التعليم العام وتوثيقها،
(د ) تصميم إستمارة الشهادة الثانوية،
(هـ) تقويم الشهادة الثانوية،
(و ) أي اختصاصات أو سلطات أخرى منصوص عليها في هذا القانون أو اللوائح الصادرة بموجبه.
