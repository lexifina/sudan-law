# المادة 25 — اختصاصات إدارة الامتحانات بالولاية وسلطاتها.
تكون لإدارة الامتحانات بالولاية الاختصاصات والسلطات الآتية:
( أ) أن تضع بموافقة المركز القومي للمناهج والبحث التربوي،
امتحانات مرحلة الأساس بالولاية وأن تقوم بإجرائها،
(ب) تصميم إستمارة شهادة مرحلة الأساس،
(ج ) إصدار نتائج مرحلة الأساس،
(د ) تقويم شهادة مرحلة الأساس.
