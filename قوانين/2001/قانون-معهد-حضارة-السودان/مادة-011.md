# المادة 11 — اختصاصات المجلس العلمي.
يختص المجلس العلمي بالشئون العلمية ومع عدم الإخلال بعموم ما تقدم تكون له الاختصاصات الآتية:
(أ ) إجازة البرامج والسياسات العلمية ومشاريع البحوث،
(ب) متابعة نشاطات المعهد العلمية والبحثية،
(ج) التوصية للمجلس بتخصيص المنح العلمية والجوائز التقديرية،
(د ) أي اختصاصات أخرى يوكلها له المجلس أو الوزير.
