# المادة 23 — إنشـاء مجلس الأساتذة وتشكيله.
ينشأ مجلس للأساتذة بالجامعة ويشكل على الوجه الآتي:
( أ) المدير رئيساً
(ب) نائب المدير عضواً
(ج ) مساعد المدير للشئون المالية والإدارية عضواً
(د ) مساعد المدير للشئون العلمية عضواً ومقرراً
(هـ ) مساعد المدير لشئون الطلاب عضواً
(و ) أمين المكتبة عضواً
(ز ) عمداء الكليات والمدارس أعضاء
(ح ) مديرو المعاهد والمراكز أعضاء
(ط ) رؤساء الأقسام ووحدات التدريب أعضاء
(ى ) جميع أعضاء هيئة التدريس ممن هم في مرتبة الأستاذية أعضاء
(ك ) ممثل واحد لكل من المدارس والمعاهد والمراكز من أعضاء هيئة التدريس عضواً
