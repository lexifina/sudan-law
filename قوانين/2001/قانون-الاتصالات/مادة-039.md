# المادة 39 — تشكيل اللجنة الفنية واختصاصاتها.
(1) يشكل المجلس لجنة فنية لرخص الاتصالات اللاسلكية وتتكون من:
(أ ) ممثل للهيئة القومية للاتصالات رئيساً
(ب) ممثل للاستخبارات العسكرية عضواً
(ج ) ممثل لجهاز الأمن الوطني عضواً
(د ) ممثل لسلاح الإشارة عضواً
(هـ) ممثل لوزارة الداخلية عضواً
(2) تختص اللجنة بالآتي:
(أ ) رفع التوصيات للمجلس فيما يختص بطلبات أجهزة اللاسلكي وتجديدها،
(ب) وضع لائحة داخلية لتنظيم إجراءات اجتماعاتها،
(ج ) أية اختصاصات أخرى حسبما يقرره المجلس،
(3) يجوز للجنة بموافقة المجلس تعيين مقرر لها.
(4) يحدد المجلس مكافآت رئيس اللجنة الفنية وأعضائها والمقرر.
