# المادة 44 — العقوبات.
(1) مع عدم الإخلال بأى عقوبة أشد يكون منصوصاً عليها في أي قانون آخر يعاقب كل شخص يخالف أحكام هذا القانون
أو اللوائح أو الأوامر الصادرة بموجبه بالسجن مدة لا تزيد على ستة أشهر أو بالغرامة أو بالعقوبتين معاً.
(2) فى جميع الأحوال التي ترتكب فيها مخالفة لأحكام هذا القانون يجوز للمحكمة أن تأمر:
(أ ) بمصادرة المواد والأجهزة أو المعدات موضوع المخالفة لصالح الهيئة،
(ب) بإلغاء الترخيص.
