# المادة 5 — الجرائم الإرهابية.
كل من يقوم أو يحرض أو يشرع في القيام أو يسهل فعلاً أو قولاً أو نشراً بارتكاب فعل تنفيذاً لغرض إرهابي
على الدولة أو أمنها الاجتماعي أو رعاياها أو ممتلكاتها أو مرافقها أو منشآتها العامة أو الخاصة بارتكاب
جريمة إرهابية أو سياسية يعاقب عند الإدانة بالإعدام أو السجن المؤبد.
