# المادة 17 — نشرة الإصدار.
يتم طرح صكوك التمويل بوساطة الجهة المصدرة بموجب نشره إصدار ويجب أن تشمل هذه النشرة إلى جانب أي متـطلبات أخرى حسبما تحدده اللوائح المعلومات الآتية:
( أ) القيمة الاسمية للإصدار،
(ب) وصفاً وافياً للمشروع الذي تستخدم فيه حصيلة الإصدار،
(ج) بيان الجدوى الاقتصادية أو الاجتماعية أو الدوافع أو المصلحة من وراء إنشاء المشروع أو تطويره بحسب الحال،
(د) مواعيد فتح باب الاكتتاب العام وقفله،
(هـ) فئة الصكوك وقابليتها للتجزئة،
( و) أسماء المديرين والمغطين ووكلاء البيع ( إن وجدوا )،
( ز) اسم الشخص المفوض الذي يرعى مصالح أصحاب الصكوك ووكلاء الدفع،
(ح) نسبة توزيع الأرباح بالنسبة لصكوك المضاربة وصكوك الاستثمار الأخرى،
(ط) أية معلومات أخرى ترى اللجنة ضرورة إضافتها لطمأنة المستثمر وحفظ حقوقه.
