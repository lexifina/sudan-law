# المادة 24 — أنواع المعاشات.
تكون المعاشات والمكافآت التي تمنح للضباط وعائلاتهم من الأنواع الآتية:
( أ) معاشات ومكافآت عادية للضباط،
(ب) معاشات ومكافآت عادية لعائلات الضباط،
(ج ) معاشات خاصة للضباط،
(د ) معاشات خاصة لعائلات الضباط،
(هـ) معاشات ومكافآت للضباط الذين يعادون للخدمة،
(و ) مكافآت خاصة لعائلات الشهداء،
(ز ) معاشات الضباط الذين يعينون في مناصب وزارية،
(ح ) منحة نهاية الخدمة،
(ط ) مكافآت وسام الخدمة الطويلة الممتازة.
