# المادة 27 — مجالس الأقسام والوحدات.
(1) ينشـأ في كل قسم أو الوحدة مجلس برئاسة رئيس القسم أو الوحدة وعضوية جميع أعضاء هيئة التدريس بالقسم أو الوحدة.
(2) تكون مهام مجلس القسم أو الوحدة بالإضافة إلى ما يضمن في النظم الأساسية واللوائح، تنظيم
النشاط العملي والإدارى بالقسم أو الوحدة وذلك تحت إشراف مجلس الكلية أو المدرسة أو المعهد
أو المركز.
