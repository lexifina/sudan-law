# المادة 28 — مجالس الأقسام ووحدات التدريب.
(1) ينشأ في كل قسم أو وحدة تدريب مجلس برئاسة رئيس القسم أو وحدة التدريب وعضوية جميع أعضاء هــيئة التدريس بالقسم أو وحدة التدريب.
(2) تكون مهمة وحـدة القسم أو وحدة التدريب بالإضافة إلى ما يضمن في النظم الأساسية واللوائح تنظيم النشاط العلمي والإداري بالقسم أو وحدة التدريب وذلك تحت إشراف مجلس الكلية أو المدرسة أو المعهد أو المركز.
