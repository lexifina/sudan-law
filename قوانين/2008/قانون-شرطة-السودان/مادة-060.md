# المادة 60 — جرائم الإخلال بالحراسات وحماية الأموال العامة.
(1) كل شرطي يتعمد الإخلال بواجبه في حراسة المتهمين المقبوضين أو المحكـوم
عليهم أو في حمـاية الممتلكـات أو المحافظة عليها أو أي أموال يعهد إليه بحراستها يعاقب بالسجن مدة لا تجاوز سبع سنوات أو بالغرامة أو بالعقوبتين معاً ويعاقب بالفصل من الخدمة.
(2) أى شرطي يتستر أو يتآمر أو يحاول تسبيب أي شغب أو عصيان داخل الحراسات أو السجن أو لا يعمل جاهداً لفض ذلك الشغب أو العصيان أو يشترك في ذلك الشغب أو العصيان يعاقب بالسجن مدة لا تجاوز خمس سنوات أو بالغرامة أو بالعقوبتين معاً كما تجوز معاقبته بالفصل من الخدمة.
(3) كل شرطي يهمل في حراسة المتهمين أو المقبوضين أو المحكوم عليهم أو في حماية الممتلكات أو المحافظة عليها أو أي أموال تعهد إليه حراستها يعاقب بالسجن مدة لا تجاوز ثلاث سنوات أو الغرامة أو بالعقوبتين معاً كما تجوز معاقبته بالفصل من الخدمة.
