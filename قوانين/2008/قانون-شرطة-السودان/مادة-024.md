# المادة 24 — الرتب النظامية.
(1) تكون الرتب النظامية لضباط الشرطة على الوجه الآتي:
( أ) فريق أول،
(ب) فريق،
(ج) لواء،
(د ) عميد،
(هـ) عقيد،
(و) مقدم،
(ز) رائد،
(ح) نقيب،
(ط) ملازم أول،
(ى) ملازم.
(2) تكون الرتب النظامية لضباط الصف والجنود على الوجه الآتى:
( أ) مساعد،
(ب) رقيب أول،
(ج) رقيب،
(د) عريف،
(هـ) وكيل عريف،
(و ) جندي.
