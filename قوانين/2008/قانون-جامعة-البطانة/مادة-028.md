# المادة 28 — مجالس الأقسام ووحدات التدريب
(1) ينشأ في كل قسم أو وحدة تدريب مجلس برئاسة رئيس القسم أو وحدة التـدريس وعضـوية جميع أعضاء هيـئة التدريس بالقسم أو وحدة التدريب.
(2) تكون مهمة مجلس القسم أو وحدة التدريب بالإضافة إلى ما يضمن في النظم الأساسية واللوائح، تنظيم النشاط العلمي والإداري بالقسم أو وحدة التدريب وذلك تحت إشراف مجلس الكلية أو المدرسة أو المعهد أو المركز.
