# المادة 42 — مشتملات محضر التحري.
يشتمل محضر التحري على الآتى:
( أ) أى تحريات أولية،
(ب) أقوال المبلغ أو الشاكى،
(ج ) أقوال الشهود،
(د ) أقوال المتهم،
(هـ) أى تقارير لها صلة بالدعوى الجنائية موضوع التحري،
(و ) قرار توجيه التهمة،
(ز ) أى إجراءات تتخذ في التحري،
(ح ) أى قرار لوكيل النيابة بشطب الدعوى الجنائية،
(ط ) خلاصة التحري وقرار الرفع للمحاكمة.
