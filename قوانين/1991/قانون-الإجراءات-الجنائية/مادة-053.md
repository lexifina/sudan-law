# المادة 53 — وظائف المتحرى.
تكون للمتحرى الوظائف الآتية:
( أ) إجراء التحري الأولى وفتح الدعوى الجنائية أو التوصية بفتح الدعوى الجنائية،
(ب) تدوين محضر التحري وحفظه،
(ج ) مباشرة إجراءات التحري،
(د ) رفع المحضر أثناء التحري للجهات المختصة والتوصية لديها بأى إجراء،
(هـ) رفع المحضر فور إكتمال التحري إلى وكيل النيابة لتلخيصه ورفعه إلى المحكمة.

> حاشية: (26) قانون رقم 8 لسنة 2002 .
