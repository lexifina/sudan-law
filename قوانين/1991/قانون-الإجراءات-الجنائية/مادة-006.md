# المادة 6 — أنواع المحاكم الجنائية.
تكون المحاكم الجنائية القومية من الأنواع الثمانية الآتية:
( أ) المحكمة القومية العليا،
(ب) محكمة استئناف،
(ج ) محكمة جنائية عامة،
(د ) محكمة جنائية أولى،
(هـ) محكمة جنائية ثانية،
(و ) محكمة جنائية ثالثة،
(ز ) محكمة جنائية شعبية (محكمة مدينة أو ريف)،
(ح ) أى محكمة جنائية خاصة ينشئها رئيس القضاء بموجب قانون الهيئة القضائية لسنة 1986، أو تنشأ بموجب أي قانون آخر.

> حاشية: (5) قانون رقم 17 لسنة 2009 ، قانون رقم 20 لسنة 2012 قانون التعديلات المتنوعة " القوانين المتأثرة بإنفصال جنوب السودان لسنة 2012 .
