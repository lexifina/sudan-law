# المادة 20 — التعاقد بشأن المسائل الاستشارية والبحوث والمخترعات والاكتشافات.
(1) يجوز للمركز أن يتعاقد مع أي شخص أو هيئة في داخل
السودان أو خارجه للقيام بأعمال استشارية أو لإجراء بحث
خاص بغرض اكتشاف أو اختراع أو تحسين أية عملية أو طريقة أو إنتاج جهاز وفقاً لأية شروط يتفق عليها.
(2) تؤول حقوق الاكتشاف أو الاختراع أو التحسين بموجب أي اتفاق يبرمه المركز
بموجب البند (1) أما إلى المركز أو إلى الطرف الآخر أو إليهما معاً وفقاً لما يتفق عليه.
