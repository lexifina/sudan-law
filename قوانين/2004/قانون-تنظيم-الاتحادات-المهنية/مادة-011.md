# المادة 11 — النظام الأساسي واللوائح.
(1) مع مراعاة أحكام هذا القانون واللوائح الصادرة بموجبه يكون لكل اتحاد مهني عام نظاماً أساسياً يتضمن على وجـه الخصوص:
( أ) اسم الاتحاد المهني العام وتاريخ تكوينه ومقره وعنوانه،
(ب) الأغراض التي أنشئ من أجلها إضافة للأغراض العامة الواردة في هذا القانون،
(ج) شروط اكتساب العضوية وحالات فقدها،
( د) حقوق الأعضاء وواجباتهم،
(هـ) أسس ونسب تكوين المؤتمرات العامة والمؤتمرات الولائية والجمعيات العمومية للاتحاد المهني العام والولائي والجمعيات المهنية المتخصصة،
(و ) أسس ونسب تكوين المجلس العام والمكاتب التنفيذية،
(ز ) طريقة دعوة المؤتمرات والجمعيات العمومية للانعقاد،
(ح ) طريقة دعوة المجلس العام والمجلس الولائي والمكاتب التنفيذية للانعقاد،
(ط ) تنظيم العلاقة بين الاتحاد المهني العام والاتحادات المهنية الولائية والجمعيات المهنية المتخصصة،
(ى ) مصادر الأموال وحفظها والتصرف فيها واستثمارها،
(ك ) إعداد الموازنة وإجراءات المراجعة وبداية السنة المالية ونهايتها،
(ل ) طريقة تعديل النظام الأساسي واللوائح،
(م ) إجراءات حل الاتحاد المهني العام والاتحادات المهنية الولائية،
(ن ) إجراءات تكوين وقبول الجمعيات العلمية المتخصصة التابعة للاتحاد المهني العام المعني،
(س) وضع المعايير واللوائح المنظمة لأعمال ومراقبة بيوت الخبرة والمكاتب المهنية بما لا يتعارض مع أي قانون آخر.
(2) يجوز للاتحاد المهني العام أن يضع لوائح داخلية تتضمن تفصيلاً للقواعد الواردة في النظام الأساسي أو المبادئ العامة الواردة فيه، كما له أن يفوض الاتحادات المهنية الولائية لإصدار اللوائح الداخلية الخاصة بها بما لا يتعارض مع اللوائح الداخلية التي يصدرها الاتحاد المهني العام.

> حاشية: (6) قانون رقم 40 لسنة 1974 .
