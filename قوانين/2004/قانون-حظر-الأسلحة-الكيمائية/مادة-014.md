# المادة 14 — حظر تصنيع أو استحداث أو إنتاج أو حيازة أو نقل أو استعمال أو الترخيص باستخدام الأسلحـة الكيمائية.
لا يجوز لأي شخص أن:
(أ ) يستحدث أو يصنع أو ينتج أو يحوز أو يخزن أو يحتفظ
بأي طريقة أي أسلحة كيمائية،
(ب) ينقل بطريق مباشر أو غير مباشر أي أسلحة كيمائية
لشخص آخر،
(ج ) يستعمل أي أسلحة كيمائية،
(د ) يساعد أو يشجع أو يحرض بأي طريق أي شخص آخر للإشتراك في أي نشاط محظور بموجب الاتفاقية،
(هـ) يستخدم أراضي السودان معبراً لنقل أي أسلحة كيمائية لطرف ثالث.
