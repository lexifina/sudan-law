# المادة 13 — اختصاصات أمانة التدريب بالولاية.
تكون لأمانة التدريب بالولاية الاختصاصات الآتية:
(أ ) حصر الحاجات التدريبية بوحدات الولاية،
(ب) دراسة الحاجات التدريبية وتحديد الأسبقيات وإعداد مشروع الخطة السنوية للتدريب وتقديمها للأمانة العامة،
(ج ) تنفيذ خطة التدريب السنوية بالتنسيق مع الأمانة العامة للمجلس وإدارات التدريب بالولاية ومؤسسات التدريب،
(د ) متابعة وتقييم التدريب بالتنسيق مع إدارات التدريب بالولاية،
(هـ) تقديم العون الفنى اللازم لمؤسسات القطاع الخاص بالولاية،
(و ) التصديق بإنشاء مراكز التدريب الولائية وتحديد مستوياتها.
