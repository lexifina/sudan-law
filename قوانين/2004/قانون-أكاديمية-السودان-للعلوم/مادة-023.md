# المادة 23 — إنشـاء مجلـس الأساتذة وتكوينه.
ينشأ مجلس للأساتذة بالأكاديمية ويشكل على الوجه الآتي:
( أ) المدير رئيساً
(ب) نائب المدير عضواً
(ج ) الوكيل عضواً
(د ) أمين المكتبة عضواً
(هـ) مديرو الأجهزة البحثية ورؤساء القطاعات المنتسبة للوزارة أعضاء
(و ) خمسون عضواً من أعضاء هيئة التدريس أعضاء
(ز ) أمين الشئون العلمية بالأكاديمية عضواً ومقرراً
