# المادة 34 — سلطة إصدار اللوائح والقواعد والأوامر.
يجوز للمجلس بموافقة مجلس الوزراء أن يصدر اللوائح والأوامر والقواعـد اللازمة لتنفيذ أحكام هذا القانون، ومع عدم الإخلال بعموم ما تقدم يجوز أن تتضمن تلك اللوائح:
( أ) تنظيم مهنة المحاسبة والمراجعة وتحديد مجالاتها،
(ب) قواعد آداب وسلوك مهنة المحاسبة والمراجعة،
(ج ) أى مؤهلات أو شروط إضافية للقيد في السجل،
(د ) مناهج امتحانات المعادلة للقيد في السجل، وفقاً للزمالة السودانية أو ما يعادلها،
(هـ) نماذج السجلات والدفاتر وكيفية القيد فيها،
(و ) منح شهادات التسجيل والتراخيص وممارسة مهنة المحاسبة والمراجعة،
(ز ) محاسبة المقيدين بالسجل وتحديد المخالفات وفرض الجزاءات عليها،
(ح ) تحديد الرسوم،
(ط ) شروط خدمة المسجل ونائبه والعاملين بالمجلس.
الجدول
