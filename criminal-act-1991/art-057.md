# المادة 57 — دخـول وتصوير المناطق والأعمال العسكرية.
يعاقب بالسجن مدة لا تجاوز سنة أو بالغرامة أو بالعقوبتين معاً من:
( أ) يدخل دون إذن أو عذر مشروع منطقة عسكرية، أو
(ب) يعمل دون إذن مشروع صورة أو تخطيطاً أو رسماً أو نموذجاً لأي منطقة أو عمل عسكري
أو موقع يمكن أن يكون تصويره بأي وجه مفيداً للعدو أو لأى شخص خارج على الدولة، أو
(ج) يوجد على مقربة من أي منطقة أو عمل عسكري وهو يحوز، دون إذن أو عذر مشروع، أي جهاز من أجهزة التصوير أو أي مادة تصلح لعمل الصور أو التخطيطات أو الرسوم أو النماذج.
